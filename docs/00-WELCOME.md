# Welcome to evaad v0.5

**evaad** (एवाद) is a balance-first debate social app. Every topic shows
both sides equally, with merit-based ranking so the strongest arguments
rise on each side.

## What's new in v0.5

- **Fabulous new design** — glassmorphism, animated gradients, glow effects
- **Visual balance bars** — see the For/Against split at a glance
- **Multiple sort modes** — Hot, New, Top, Controversial
- **Toast notifications** — elegant success/error feedback
- **Shimmer loading** — beautiful skeleton screens while loading
- **Topic stats** — views, likes, argument counts in real-time
- **Auto-resizing compose box** — textarea grows as you type
- **Enhanced animations** — smooth transitions, hover effects, micro-interactions
- **5 seed topics** — richer, more realistic debate data
